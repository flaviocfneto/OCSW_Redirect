Link straight to a course search

Our course finder only runs a search when someone submits its form, so an ordinary link can't open a filtered list. This page shows a small workaround: a link that fills in the form for you and sends you to the results.

How it could look on a web page

Each tile is an ordinary link. Click one and the live course finder opens with that search already run.

How it works

        
Nothing changes on the course finder. The link carries the search in its address, and this page hands it over in the format the course finder expects.

        
    
          
  1. Someone clicks a link
    ending in something like
    ?kw=digital&venue=1177
    2. 
          
  2. This page reads the search
    and fills in the same fields as the course finder's form
    3. 
          
  3. The browser submits it
    and the visitor lands on the real results page
    4. 
        

        
Good to know

        
    
          
  • Pressing Back on the results takes the visitor to where they came from.
    • 
          
  • Individual courses already have their own address, for example /Course/Details/16256, so they need none of this.
    • 
          
  • The cleanest long-term fix is for Cognisoft to accept search terms in the course finder's own address. These links could then point there directly.
